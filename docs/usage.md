# 使用指南

[返回 README](../README.md)

## 账号与恢复码

注册后请立即妥善保存恢复码，再继续使用。邮箱目前只是未经验证的登录标识，本站不发送验证、邀请或找回密码邮件，也不会根据邮箱域名授予权限。

忘记密码时使用恢复码找回。恢复码只能使用一次，成功后会换发新码，并使旧会话失效。请不要将密码、恢复码、激活链接或会话内容提交到 GitHub Issue。

## 导入课表

1. 从学校教务系统或已有日历工具取得 `.ics` 文件。BumpFree 不需要你的教务系统密码，也不要求 WakeUp 分享口令。
2. 进入“我的课表”，选择文件，核对学期名称、第 1 周周一及学期周数。当前导入界面固定转换到 `Asia/Shanghai`（北京时间），没有时区选择控件。
3. 检查预览中的课程名、上课时间、教师、地点和周次。
4. 确认保存。默认覆盖同名课表；重复导入不会增加副本。覆盖前会确认，失败时数据库事务保留旧课表；也可以显式新建副本。
5. 在“已存课表”切换当前课表、编辑课程，或补充文件未提供的教师和地点。

原始 ICS 在浏览器 Web Worker 中解析。确认后仅上传结构化课程；服务器不保存原始 ICS 文件。人工处理附件是另一种独立流程，不适用此说明。

### 试用示例

[示例 ICS](../examples/demo-schedule.ics) 包含 5 门虚构课程，其中一门为单周实验课。将第 1 周周一设为 **2026-08-31**、学期设为 **20 周**；导入使用 **Asia/Shanghai**，在日历中切到开学后的日期查看。

### ICS 导入支持范围

- 字段：`SUMMARY`、`DTSTART/DTEND` 或小时/分钟 `DURATION`、`LOCATION`、备注。教师读取 `X-TEACHER` 或备注中的“教师/老师/Teacher/Instructor:”；缺失时不猜测。
- 重复与例外：日/周/月/年 `RRULE`、单双周、`RDATE`（含 PERIOD）、`EXDATE`、同 UID 的 `RECURRENCE-ID` 精确调课，以及同一时区的 `THISANDFUTURE`。相同 UID 的修订按 `SEQUENCE` 和修改时间选择。
- 时区：支持读取 UTC、IANA 时区与内嵌 `VTIMEZONE`。当前界面固定转换到 `Asia/Shanghai`；无时区的时间使用文件时区或此输出时区。底层解析器支持指定其他输出时区，但界面暂不提供选择。日历按查看者设备时区显示。
- 默认学期：西南石油大学 2026–2027 秋季，第 1 周周一为 **2026-08-31**，共 20 周；导入前可以修改。课程以 ICS 实际日期为准，不额外推测停课或补课。
- 限制：单文件 2 MiB、最多 2000 条 VEVENT、5000 个实际课程实例，最终每份课表最多 500 条周次记录；独立解析线程 5 秒超时终止。
- 暂不支持：占用全天、跨午夜、秒级课程、不存在的夏令时时刻、跨时区 `THISANDFUTURE` 等。透明日程/不占用时间的提醒会跳过并提示；不支持的情况会明确拒绝。

这些是当前支持范围，不代表完整实现所有 iCalendar 特性。出现问题时，请提交匿名化的最小复现文件。

### 其他导入方式

“其他导入方式与人工处理”保留标准/松散文本、HTML、DOCX、XLS/XLSX/CSV/TXT 抽取及人工处理。自动抽取文件最多 5 MiB，人工处理附件最多 2 MiB。

复杂办公文件可能触及 Workers Free CPU 限制，建议优先使用 ICS。PDF 服务端解析与自动 OCR 尚未开放。

## Room 与共享日历

房主创建 Room 后，按昵称搜索并邀请已注册用户。对方接受邀请后，其当前启用的课表会进入共享日历。

- **周视图**：按时间轴对照全体成员的课程。
- **月视图**：浏览更长时间范围的安排。
- **按人查看**：选择成员，聚焦该成员的课表。
- **临时 busy**：成员可以添加自己的临时占用；这不是对原课程的修改。

调课通知导入目前只新增一次性 busy 时间，不会自动取消、删除或修改原课表中的课程。若原课程确实取消，请同时核对并手动处理。

日历展示已录入的安排，不等于成员已经同意参加活动，也不能发现未录入的私人安排。

## 私密与公开分享

Room 默认私密。房主可开启公开只读链接，方便向非成员展示安排。

| 公开访问者可见                                   | 公开访问者不可见                 |
| ------------------------------------------------ | -------------------------------- |
| 成员昵称、当前课表中的课程、教师、地点、课程备注 | 邮箱、非当前课表、密码或会话字段 |
| 隐藏标题与备注的忙碌时段，仍关联成员昵称         | busy 的私人标题与备注            |

**公开课表中的课程备注也会公开**，请勿填写身份证明、联系方式、私人事项等内容。房间过期后关闭外部公开读取；既有成员仍可查看。

## 常见问题

**导入成功，但日历是空的？** 确认第 1 周周一与课程周次正确、该课表已设为当前，并将日历切到课程实际发生的日期。示例课表不是按“今天”动态生成的。

**教师或地点没有显示？** 先检查 ICS 是否包含相应字段。文件未提供时，可在课程管理中手动补充。

**会自动匹配学校作息或节假日吗？** 不会。BumpFree 以文件中的实际起止时间和例外日期为准，不替学校猜测补课、停课或节次时间。

**可以用旧 Supabase 账号直接登录吗？** 当前 D1 部署没有自动迁入旧账号和历史数据；旧 Auth 凭据不能直接用于本版。

**能一直免费使用吗？** 可在 Cloudflare 免费额度内运行，但配额由账号共享，附件、请求和数据库读写都可能触及限制。详见 [免费额度](deployment.md#免费额度与容量)。
